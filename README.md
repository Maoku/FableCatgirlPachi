# FableCatgirlPachi

Claude Fable 5 で1枚画像から作ってみる技術検証プロジェクト

猫耳キャラクターをテーマにした、ブラウザで遊べるパチンコゲーム。
`Docs/pachi.png` の台画像の上に物理シミュレーションの盤面を重ねて動作します。

公開版: https://maoku.github.io/FableCatgirlPachi/

![盤面](Docs/pachi.png)

## 技術スタック

- **TypeScript** + **Vite**
- **PixiJS v8** — WebGL 描画
- **Rapier2D** (WASM) — 物理エンジン(CCD 有効で高速球のすり抜けを防止)

## 起動方法

```bash
npm install
npm run dev      # http://localhost:5173
```

ビルドは `npm run build`(型チェック込み)、成果物のプレビューは `npm run preview`。

### LAN 内の別端末から遊ぶ

dev サーバーは全インターフェースで listen する設定(`server.host: true`)なので、
起動時に表示される **Network** の URL(例: `http://192.168.x.x:5173`)を
同じネットワークの PC・スマホのブラウザで開けばそのまま遊べます。
接続できない場合は macOS の「ファイアウォール」で node への着信許可を確認してください。

## 遊び方

- **発射強度** スライダーで狙いを調整し、**「玉を打つ」ボタン長押し**(または **Space 長押し**)で連続発射
- 玉はレールを上って盤面へ。強度 0.5 未満はファウル(盤面に届かず回収)
- **スタートチャッカー**(緑)に入賞すると賞球 +3 と抽選(保留最大4)
- 図柄が3つ揃うと **大当り**(確率 1/199)。アタッカー(橙)が10ラウンド開放され、入賞ごとに賞球 +15
- 持ち玉が尽きたら **+500 補給** ボタン

## 動画演出

- 図柄変動中は液晶エリアで抽選動画(2本からランダム)がループ再生され、
  大当り告知時には当り動画(2本からランダム)が1回再生されます
- 音声は既定でミュート(ブラウザの自動再生ポリシー対応)。**🔇/🔊 ボタン**で
  切り替えられ、設定は localStorage に保存されます
- 動画素材は `public/assets/movie/` に配置。読み込みに失敗した環境でも
  従来の図柄演出のみで動作します

## エディットモード

「🔧 エディットモードへ」で盤面を編集できます。

- **ツール**: 選択 / 釘 / 壁 / 風車 / スタート / アタッカー / アウト
- クリックで配置、ドラッグで移動(壁はドラッグで線を引き、端点も個別に動かせる)
- 選択中オブジェクトは右パネルで半径・回転速度・幅・種別を編集、Delete キーで削除
- レイアウトは **localStorage に自動保存**。JSON の **エクスポート / インポート** にも対応
- 「プレイモードへ」で物理ワールドに反映
- 初期配置は `src/layout/default.json`。エクスポートした JSON で上書きすれば初期配置を差し替えられる

## 自動プレイ

- **玉数上限**・**時間上限**(併用可)を指定して「自動プレイ開始」
- 条件到達または持ち玉切れで自動停止し、理由を表示
- 実行中は発射数と経過時間をライブ表示

## 構成

```
src/
├── main.ts              # 起動・配線・ゲームループ
├── types.ts             # レイアウト JSON の型
├── core/
│   ├── constants.ts     # 盤面ジオメトリ・物理定数
│   ├── PhysicsWorld.ts  # Rapier ラッパ(衝突イベント・スタック玉回収)
│   ├── Game.ts          # ゲーム状態(発射・抽選・大当り・持ち玉)
│   └── BoardRenderer.ts # 釘・壁・入賞口のオーバーレイ描画
├── layout/defaultLayout.ts  # 初期盤面(画像に合わせた配置)
├── editor/              # エディットモードとレイアウト永続化
├── game/AutoPlayer.ts   # 自動プレイ
├── fx/EffectsLayer.ts   # 図柄変動・リーチ・大当り演出
├── fx/MoviePlayer.ts    # 演出動画(抽選中ループ・当り告知)の再生
└── ui/Hud.ts            # DOM 操作パネル
```

物理は 100px = 1m のスケールで、盤面の論理座標は `pachi.png` のピクセル座標(1123×1401)と一致します。
